## Contenu

- Âges 0 à 85 : tiret dans toutes les colonnes.
- Diagonale de départ : 100000 à l'âge 86 (1910), 87 (1909), … 96 (1900) ; tiret au-dessus.
- Toutes les colonnes portent des valeurs jusqu'à l'âge 117 (valeur 0 dans les onze colonnes), puis tiret aux âges 118 à 121.
- Les nombres sont imprimés avec une espace fine des milliers (« 100 000 », « 9 016 ») ; transcrits sans espace.
